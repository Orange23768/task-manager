# Frontend 
## Przeznaczenie 
### Frontend to warstwa aplikacji lub strony internetowej, z którą użytkownik wchodzi w bezpośrednią interakcję — wszystko, co widać i klika w przeglądarce: układ, teksty, przyciski, formularze i animacje. Odpowiada za wygląd oraz obsługę interfejsu i działa po stronie klienta, czyli w przeglądarce.
## Planowane widoki - lista zadań, - formularz dodawania,- formularz edycji. 
## Technologie - HTML, - CSS, - JavaScript.
